## 제품 방향

- 한국어 사용자에게 입문·중급 프랑스어를 짧은 텍스트 문제로 제공합니다.
- 홈에서 3·5문제를 시작하고, 코스별 10문제·복습·재도전으로 이어갑니다.
- 문제의 목표는 짧게 안내하고, 해설·미니 레슨·문법 참고 내용은 필요할 때 펼칩니다.
- 문법 용어에 한국어와 프랑스어를 병기합니다.
- 루의 옷장·방 꾸미기와 학습 기록을 학습 보상으로 연결합니다.
- 기존 문제 ID와 저장 데이터를 이어서 사용합니다.

## 완료된 기능

### 학습·채점·해설

- 입문·중급별 추천, 짧은 한 판, 코스 선택, 자동 저장과 이어하기.
- 선택·빈칸·단어·문장 입력·단어 배열. 코스 순서는 미리 작성되어 있고 선택지와 단어 카드의 표시 순서는 섞입니다. 짧은 판과 복습은 저장된 학습 상태에 따라 기존 문항을 선정합니다.
- 210문항에 루의 연습 목표 연결. 화면이 짧을 때는 **연습 목표·단어**에서 안내를 펼칩니다.
- 선택 문제의 완성 문장은 정답 확인 전까지 빈칸으로 표시합니다. 빈칸 문제의 어휘 안내에서 정답 단어를 바로 노출하던 부분을 수정했습니다.
- 등록된 허용 답안으로 시간 표현·조건절 위치 등의 변형을 인정합니다. 일부 자연스러운 대안은 뜻을 인정한 뒤 목표 표현으로 다시 안내합니다.
- 입력칸 바로 아래의 오답 표시, 악센트 안내, 힌트·정답 보기, 반복 오답 시 카드 도움.
- 문장 전체 입력은 자동 줄바꿈을 지원합니다. Enter로 확인하고 Shift+Enter로 줄을 바꿉니다. 한글 등 입력 조합 중의 Enter는 채점에서 제외합니다.
- **해설 보기 → 조금 더 알아보기 → 문법 보기**로 설명을 확장합니다. 해설을 열면 해설에 초점이 머물고, 문법을 닫으면 문제의 입력·배열·읽던 위치로 돌아갑니다.
- 직접 회상한 정답에 따라 1·3·7·14일 간격으로 복습합니다. 오답·도움을 사용한 문제를 재도전하며 중복 완료로 XP나 스탬프를 다시 지급하지 않습니다.

### 기초 표현·단어장·문법

- 기초 표현 확인, 뜻 고르기 퀴즈, 즐겨찾기, 틀린 표현과 카드 복습.
- 중단한 기초 레슨을 홈의 이어하기 버튼에서 다시 엽니다.
- 단어장 전체 표현을 12개 주제로 접어 표시하고, 주제마다 **6개 표현 복습**을 제공합니다. 검색·저장한 표현·틀린 표현으로도 복습할 수 있습니다.
- 복습 카드의 뜻과 **용법 보기**를 제공하며, 카드 뒤집기 후 키보드 초점을 유지합니다.
- 문법 도서관의 네 분류를 펼쳐 탐색하고 한국어·프랑스어·활용형으로 검색합니다.
- 단어장과 문법 검색에서 Enter로 결과에 이동합니다. 표현 저장, 상세 카드 닫기, 검색 전후에 펼쳐둔 주제와 관련 초점을 복원합니다.
- 문법 개인 열람 횟수와 문제별 문법 연결을 저장합니다.

### 루의 방·옷장·보상

- 방 소품 **33종**, 옷·안경·머리 장식 **30종**, 털 무늬 3종과 네 포즈를 제공합니다. 포즈는 자동 전환도 선택할 수 있습니다.
- 하루 완료한 문장 연습이 3·10·20문제에 도달할 때마다 스탬프 1개씩, 최대 3개를 적립합니다.
- 무료 선물 화분·책·러그는 목표 달성 1·3·7일에 받습니다. 나머지 방 소품 30종은 1~8개 스탬프로 구매합니다.
- 착용 아이템 4종은 기본 제공하며 나머지 26종은 1~6개 스탬프로 구매합니다. 옷·안경·머리 장식을 조합하고 해제할 수 있습니다.
- 소품과 루를 이동·확대·축소·회전·반전하고 소품 순서를 바꿉니다. 벽 6색과 바닥 3종을 선택합니다.
- 한 방에 소품을 24개까지 배치하며, 보유 소품은 여러 개 놓을 수 있습니다. 착용 아이템은 방 소품 수에 포함되지 않습니다.
- 목록은 6개씩 넘겨 보고 배치 도구는 펼쳐 사용합니다. 편집을 닫다가 **계속 꾸미기**를 선택하면 도구와 스크롤 위치가 복원됩니다.
- 구매·미리보기·저장을 구분하며, 저장한 차림은 홈·학습·인증 카드에 반영됩니다. 배치를 취소해도 구매 이력은 보존합니다. 가득 찬 방에서 구매한 소품은 보관 안내를 표시합니다.
- 옷은 네 포즈에 맞춘 로컬 이미지로 표시합니다. 소품·착용 자산은 오프라인 캐시에 포함합니다.

### 달력·인증·설정

- 월간 달력과 주간 기록을 **일요일부터** 표시합니다.
- 날짜를 선택하면 상세 기록이 하단 메뉴에 가리지 않게 이동합니다. 방향키·Home·End로도 날짜를 탐색합니다.
- 주간·누적 통계는 펼쳐서 확인하며, 완료 문제 수·XP·연속 학습일을 볼 수 있습니다.
- 날짜와 학습량, 저장한 방과 차림을 담은 **1080×1350 PNG**를 저장합니다. 지원 기기에서는 파일 공유도 제공합니다.
- 카드의 경험치는 **+20 XP / 경험치**처럼 표시합니다. 과거 날짜는 당시까지의 구매·배치 이력을 사용합니다.
- 효과음 켜기·끄기, 음량 조절·미리 듣기, 느린 발음, 설치 안내와 기록 초기화를 제공합니다.

## 남은 작업

앞서 합의한 콘텐츠·학습 효과 개선 과제입니다.

| 순서 | 작업 | 진행 상태와 다음 확인 |
| --- | --- | --- |
| 1 | 짧은 판을 직접 만든 한 문장으로 마치기 | 현재는 기존 순서에서 3·5문항을 선정함. 판의 마지막 문항을 학습한 어휘의 문장 쓰기로 구성하는 설계가 남음 |
| 2 | 생활 주제별 새 상황·추가 문제·허용 답안 | 210문항과 일부 대체 답안을 제공. 주문·장소·도움 요청의 새 상황과 지연 확인용 예문, 나머지 자연스러운 답 검수 필요 |
| 3 | 틀린 규칙을 다른 문장에 적용하기 | 현재 같은 문제의 재도전과 예정 복습 제공. 성수 일치 등 오류 유형별 다른 문장으로의 연결 필요 |
| 4 | 며칠 쉬고 돌아온 학습자의 복귀 흐름 | 자동 저장·홈 이어하기·3문제 시작 제공. 익숙한 한 문장부터 시작하는 복귀용 구성과 관찰 필요 |
| 5 | 루와 주고받는 텍스트 대화 문제 | 상황에 맞춰 한마디 답하는 문항과 허용 답안 설계 필요 |
| 6 | 문법·번역 검수와 새 문항 연결 | me/te/nous/vous의 직접·간접목적어 쓰임, 선택의 lequel, 제안의 Et si on… ? 등을 문항으로 연결. 세부 예외와 한국어 단서도 검토 |
| 7 | 학습 효과·실기기 사용성 확인 | 복귀한 학생의 첫 판 완주, 일주일 뒤 처음 보는 문장의 독립 정답, 실제 휴대폰 입력·꾸미기·공유 관찰 필요 |

한국어 단서는 자연스럽게 쓰면서 주어·행동·시간·수량·부정의 정보를 프랑스어와 맞춥니다. 여러 답이 가능한 문항에는 목표 형태를 미리 안내하고 검수한 대안을 등록합니다. v1.13부터 적용한 연습 목표·대체 답안 안내를 바탕으로 이 검수를 이어갑니다.

현재 기록은 기기·브라우저에 저장됩니다. 계정 동기화·서버 백업·결제·구독·앱스토어 출시는 별도 제품화 판단이 필요한 영역입니다.
