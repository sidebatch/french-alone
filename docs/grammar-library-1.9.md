# v1.9.0 문법 목차 확장과 프랑스어 용어

기존 32개 항목에 문제 유무와 독립적인 문법 35개를 추가했습니다. 현재 목차는 67개이며 문장의 기본 17개, 동사와 표현 13개, 시제와 가정 16개, 대명사와 연결 21개입니다. 실용 기초·중급 주제를 넓히고 문어체 과거의 입문 설명을 포함했습니다. 모든 전문 문법·문학적 예외를 망라했다는 의미는 아닙니다.

## 용어 표기

- 목록과 상세 카드 제목에는 한국어 제목 다음에 프랑스어 용어를 괄호 안에 표시합니다. 긴 프랑스어는 다음 줄로 자연스럽게 내려가며 닫기 버튼을 밀어내지 않습니다.
- 상세 본문에서는 용어가 처음 나올 때만 병기합니다. 짧은 레슨은 제목·설명·표·주의점을 한 묶음으로, 문제의 짧은 해설과 기초 표현의 용법은 각각 한 묶음으로 처리합니다. 정답 문장과 문제 자체는 바꾸지 않습니다.
- 긴 복합 용어를 먼저 인식합니다. 예를 들어 동명사는 gérondif, 대명동사는 verbe pronominal로 처리하며 일부인 명사·동사로 잘못 표시하지 않습니다. 이미 병기한 프랑스어를 다시 붙이지 않습니다.
- 익숙한 교재 용어 소유형용사(adjectifs possessifs)·지시형용사(adjectifs démonstratifs)를 제목으로 사용하고, 본문에 현대 문법의 소유한정사(déterminant possessif)·지시한정사(déterminant démonstratif) 명칭도 설명했습니다.
- 정식 표기는 gérondif·subjonctif입니다. 검색에서는 gerondif처럼 악센트를 생략하거나 jerondif·subjuntif처럼 입력해도 해당 항목을 찾습니다.

## 검증

- 자동 검사 92개 통과: 전체 목차와 새 35개 항목의 일치, 기존 114개 짧은 레슨 및 210문제 연결, 프랑스어·한국어 검색, 용어 중복/복합어 처리, HTML 이스케이프, 대표 활용형·일치 예외, 기존 열람 기록 보존, 이어하기·점수·오프라인 회귀.
- Chrome에서 67개 카드를 320·390·768·1440px 너비로 열어 268개 레이아웃을 확인했습니다. 본문·표 가로 넘침, 위·아래 스크롤, 카드 닫기, 키보드 초점, 학습 화면 복귀를 검사했습니다.
- 최종 320px 검사에서 67개 카드와 210문제의 모든 설명·문법 연결, 기초 표현 72개의 용법을 다시 열었습니다. 정답 원문과 채점 결과를 유지하며 용어 병기가 렌더링되는지 비교했습니다.
- 제목·본문의 첫 등장 용어와 긴 활용표를 스크린샷으로 확인했습니다. -ons·-ant처럼 어미를 설명하는 표기는 줄 사이에서 잘라지지 않게 했습니다.
- 기존 문법 항목 ID·문제 ID·개인 열람 저장 형식을 유지했습니다. 새로운 두 모듈을 오프라인 캐시에 포함했습니다. 공개 배포 후 실제 주소에서 검색, 괄호 속 프랑스어, 개인 열람 기록, 오답 이어하기와 오프라인 문법을 확인합니다.
- 브라우저의 모바일 크기 검증이며 실제 휴대전화 기기 시험이나 전문 원어민 감수로 표시하지 않습니다.
