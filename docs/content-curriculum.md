# French Alone 1.6 · 텍스트 학습 과정

## 범위

문제와 해설은 정적 파일에 들어 있습니다. 음성 입력·발음 평가·런타임 AI 호출·유료 API는 사용하지 않습니다. 기존의 선택적 기기 발음 재생과 효과음은 유지합니다.

| 단계 | 코스 | 표현 목표 |
| --- | --- | --- |
| 내 생각 표현하기 | want / can / like | 원하는 일, 할 수 있는 일, 좋아하는 일 |
| 나의 일상 이야기 | be / have / go | 상태·위치, 소유·몸 상태, 목적지 |
| 밖에서 쓰는 한마디 | order-food / need / where | 정중한 주문, 필요·도움, 단수·복수 장소 질문 |
| 중급 · 지난 일 | past-events / past-movement / past-background | 복합과거, être와 일치, 반과거 배경과 사건 |
| 중급 · 앞일과 가정 | future-plans / real-conditions / imagined-conditions | 단순미래, si + 현재, si + 반과거와 조건법 |
| 중급 · 문장 연결 | object-pronouns / place-quantity / relative-links | le·la·les, y·en, qui·que |
| 중급 · 정확한 표현 | comparisons / opinion-links / necessity | 비교급, 이유·대조·의견, 접속법 현재 |

각 코스는 10문제입니다. 예문과 텍스트 선택 → 단어·빈칸 타이핑 → 카드 배열 → 문장 전체 타이핑 → 뜻이 주어진 어휘로 문장 바꾸기 순으로 연습합니다. 입문 확장 6코스와 중급 12코스에는 독립된 단어·활용형 타이핑 문제가 하나씩 있습니다. 기본 어휘는 앞 문제나 해당 문제에서 제공합니다. 발음을 듣고 답해야 하는 문제는 없습니다.

홈에서는 같은 콘텐츠를 5문제 또는 3문제로 나눠 연습합니다. 복습할 문제를 최대 2개 넣고 새 문제는 코스 순서를 지킵니다. 모든 문제를 만난 코스는 짧은 한 판으로도 완료됩니다. [학습·재도전·보상 규칙](play-loop.md)

입문 9코스·90문제에 중급 12코스·120문제를 더해 총 210문제입니다. 홈·코스 목록에서 수준을 선택하며, 중급은 입문을 완료하지 않아도 시작합니다. 오늘의 학습·복습·추천은 선택한 수준 안에서 구성하고, 수준별 진행 중인 판을 따로 저장합니다. 기존 입문 문제의 ID는 유지합니다.

중급은 A2–B1에서 접하는 문법을 다루는 안내형 문장 연습입니다. 전체 CEFR 과정이나 B1 인증·자유 작문 평가로 표시하지 않습니다. 단어 타이핑에는 과거분사·동사 활용도 포함합니다. 문법 용어 자체를 맞히게 하거나 설명을 길게 읽도록 요구하지 않습니다. 답과 해설은 모두 정적 콘텐츠입니다.

입력 문제는 요청한 시제·동사·대명사 형태를 연습합니다. “단순미래”, “대명사로”, “regarder 사용”처럼 과제가 정해져 있으면 뜻이 비슷해도 다른 구조는 목표 정답이 아닐 수 있습니다. 성별 미지정의 allé/allée, 위치를 바꿀 수 있는 시간 부사나 조건절 등 명시된 대안은 허용합니다. 가능한 모든 프랑스어 의역을 판별하는 기능은 아닙니다.

기초 표현은 기존 8레슨에 일상, 날씨, 시간, 숙소의 4레슨을 추가했습니다. 각 6개 표현, 합계 72개이며 표현 확인 뒤 뜻을 고르는 퀴즈를 풉니다. 이 범위를 완성된 CEFR A1 과정이라고 표시하지 않습니다.

## 해설과 채점

- 각 문제의 개별 해설은 ‘왜?’를 눌러 확인합니다. 문장 구조와 흔한 혼동은 그 안의 ‘조금 더 알아보기’에서 펼칩니다.
- 악센트는 의미·철자의 일부이므로 무조건 제거하지 않습니다. 악센트만 다른 경우 별도로 안내하고, é·è·ê·ë·à·â·ç·î·ï·ô·ù·û·ü·œ·’ 키로 입력을 돕습니다. 이 키는 힌트 사용으로 기록하지 않습니다.
- 대소문자, 공백, 문장 끝 부호와 아포스트로피 모양은 정규화합니다. 올바른 다른 답은 문제별 accepted 목록으로 명시합니다. 성별을 지정하지 않은 준비·피로 상태 문제는 남녀 형태를 모두 허용합니다.
- 단어 정렬 비교로 오타·추가 단어·누락을 구분합니다. 누락 안내에서는 요청하지 않은 정답 단어를 보여주지 않습니다.
- 선택지나 힌트를 본 학습과 직접 회상한 답을 구분합니다. ‘혼자 쓴 문장’에는 빈칸과 단어 타이핑을 포함하지 않습니다. 배열 문제를 나중에 복습에서 문장 전체로 입력하면 포함합니다. 기존 XP를 소급해서 차감하지 않습니다.
- 완료한 코스는 최근 200회 실행 기록과 별도로 보존합니다. 기존 기록에서는 완료 상태를 복원합니다. 진행 중인 기존 코스의 ID와 순서를 유지합니다.

## 검증

- Node 테스트: 210문제의 정답·카드 구성·해설, 허용 답과 잘못된 시제·일치 거절, 채점·보상, 수준별 학습·별도 초안·복습, 기존 진도 복원, 악센트·IME 입력과 오답 재도전.
- Chrome 브라우저: 신규 중급 120문제 완주, 작은 화면의 긴 문장·카드·키보드 배치, 수준 전환·이어하기와 신규 콘텐츠 오프라인 실행.
- 실제 iOS/Android 기기에서 키보드와 스피커를 직접 확인한 것은 아닙니다.
