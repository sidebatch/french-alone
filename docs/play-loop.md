# French Alone 1.6 · 짧은 학습과 보상

## 한 판의 구성

- 홈의 기본 학습은 5문제, 가볍게 학습은 3문제입니다. 전체 레슨의 코스는 기존 10문제 순서를 유지합니다.
- 입문·중급을 선택하면 같은 수준의 문제로 한 판과 복습을 구성합니다. 수준별 3·5문제, 복습, 재도전 초안은 별도 보존하고 수준 설정도 저장합니다. 기존 기록에는 입문을 기본 적용합니다.
- 새 문제가 남아 있으면 복습 예정 문제를 최대 2개 넣고 나머지는 아직 풀지 않은 문제로 채웁니다. 새 문제끼리는 원래 코스 순서를 지킵니다.
- 새 문제가 없으면 복습 예정 문제를 먼저, 이후 예정일과 기억 강도 순으로 채웁니다. 예정일 전에도 사용자가 원하는 만큼 연습할 수 있습니다.
- 이미 맞혀서 기본 XP를 받은 표현은 선택·배열 대신 타이핑으로 복습합니다. 정답을 공개하기만 한 표현은 원래 학습 형태를 유지합니다.
- 모든 문항을 마친 뒤 진도와 XP를 반영합니다. 진행 중인 입력·카드·힌트·결과는 별도의 초안으로 매번 저장합니다.

## 막혔을 때와 다시 도전

정답·오답은 하단의 짧은 안내로 보여주며 자동으로 다음 문제로 넘기지 않습니다. ‘왜?’를 눌러야 해설이 열립니다. 타이핑에서 두 번 틀리면 정답의 글자 또는 단어를 카드로 제공합니다. 악센트만 틀렸을 때는 별도로 안내합니다. ‘직접 쓸게요’로 입력 방식으로 돌아갈 수 있습니다.

힌트, 정답 공개, 잘못된 첫 시도, 카드 도움을 사용한 문제는 완료 후 재도전 목록에 넣습니다. 재도전은 그 문제들만 입력형으로 냅니다. 실제로 도움 없이 맞힌 경우에만 회복한 문제로 표시합니다. 빈칸이나 단어 하나를 문장 전체를 썼다고 계산하지 않습니다.

기본 정답 XP와 독립 회상 XP는 문항마다 한 번씩만 받습니다. 같은 실행 ID의 완료 결과를 다시 처리해도 보상·스탬프·기억 강도를 중복 반영하지 않습니다.

## 루의 방

완료한 판에서 하루 합계 3문제 이상이면 그 날짜에 스탬프 하나를 기록합니다. 같은 날 여러 판을 해도 스탬프 수는 늘지 않습니다. 연속으로 들어와야 한다는 조건이나 놓친 날의 손실은 없습니다.

| 스탬프 | 방에 생기는 물건 |
| --- | --- |
| 1개 | 작은 화분 |
| 3개 | 책 한 묶음 |
| 7개 | 포근한 러그 |

기존 학습 기록의 날짜도 반영합니다. 날짜별 기록은 최근 200판의 상세 기록과 별도로 유지합니다. 기초 표현 레슨은 기존 XP·연속 학습일에는 반영되며, 이 스탬프는 문장 연습의 완료 문항을 기준으로 합니다.

## 검증 범위와 후속 판단

저장 복원·채점·복습 구성·스탬프·기존 코스에 대한 자동 테스트와 Chrome에서의 흐름·반응형·오프라인 검증을 수행합니다. 실제 휴대폰 키보드·스피커 검증은 별도입니다.

실제 사용자의 재방문율이나 완주율이 높아졌다고 검증한 것은 아닙니다. 현재 계정·서버·사용자 분석 수집은 없습니다. 콘텐츠는 입문 90문제와 중급 120문제로 구성하며 런타임 AI 생성이나 발음 평가는 하지 않습니다.
