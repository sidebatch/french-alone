# French Alone · 짧은 학습과 보상

2026년 11월 20일, 공개 앱 v1.19.0 기준입니다. [전체 진행 현황](PROJECT-STATUS.md)

## 한 판의 구성

- 홈의 기본 학습은 5문제, 가볍게 학습은 3문제입니다. 전체 레슨의 기본 코스는 기존 10문제 순서를 유지하고, 코스별 보강 10문제는 **응용 5문제**로 나눠 풉니다.
- 입문·중급을 선택하면 같은 수준의 문제로 한 판과 복습을 구성합니다. 수준별 3·5문제, 복습, 재도전과 코스별 응용 초안은 별도 보존하고 수준 설정도 저장합니다. 기존 기록에는 입문을 기본 적용합니다.
- 새 문제가 남아 있으면 복습 예정 문제를 최대 2개 넣고 나머지는 아직 풀지 않은 문제로 채웁니다. 새 문제끼리는 기본 10문제 → 보강 10문제 → 다음 코스 순서를 지킵니다. 코스에서 직접 시작한 응용은 그 코스의 보강 문제 안에서만 선정합니다.
- 새 문제가 없으면 복습 예정 문제를 먼저, 이후 예정일과 기억 강도 순으로 채웁니다. 예정일 전에도 사용자가 원하는 만큼 연습할 수 있습니다.
- 이미 맞혀서 기본 XP를 받은 표현은 선택·배열 대신 타이핑으로 복습합니다. 정답을 공개하기만 한 표현은 원래 학습 형태를 유지합니다.
- 모든 문항을 마친 뒤 진도와 XP를 반영합니다. 진행 중인 입력·카드·힌트·결과는 별도의 초안으로 매번 저장합니다.
- 문장 연습의 예정 복습은 한 번에 최대 5문제입니다. 기초 표현 카드 복습은 단어장의 선택한 범위 또는 주제별 6개 표현으로 구성합니다.
- 홈에서 중단한 문장 연습과 기초 레슨을 이어갑니다.

## 문제와 입력

- 문제와 해설은 미리 작성한 콘텐츠입니다. 코스에서는 작성한 순서를 따르고, 짧은 판·복습에서는 학습 상태에 따라 기존 문항을 고릅니다.
- 루가 문제의 목표를 안내합니다. 짧은 화면에서 안내를 접었을 때는 **연습 목표·단어**로 펼칩니다.
- 선택 문제의 완성 문장은 정답 확인 전까지 빈칸으로 표시합니다. 빈칸 문제의 어휘 안내도 직접적인 정답 노출을 피하도록 보완했습니다.
- 단어·빈칸은 한 줄로, 문장 전체는 길이에 맞춰 줄바꿈하며 입력합니다. Enter로 확인하고 Shift+Enter로 문장 입력칸에서 줄을 바꿉니다. 입력 조합 중에는 Enter로 채점하지 않습니다.
- 허용한 어순·표현 대안은 문제별 데이터로 관리합니다. 등록된 자연스러운 대안 중 목표 구조와 다른 답은 뜻을 인정한 뒤 목표 표현으로 다시 안내합니다.

## 막혔을 때와 다시 도전

정답·오답과 틀린 단어는 입력 영역 바로 아래에 표시합니다. **확인·다시 확인·다음** 버튼은 하단에 두고 키보드가 열린 화면 높이에 맞춥니다. **해설 보기**로 설명을 열면 해설에 초점이 머뭅니다. 타이핑에서 두 번 틀리면 정답의 글자 또는 단어를 카드로 제공합니다. 악센트만 틀렸을 때는 별도로 안내합니다. **직접 쓸게요**로 입력 방식으로 돌아갈 수 있습니다.

힌트, 정답 공개, 잘못된 첫 시도, 카드 도움을 사용한 문제는 완료 후 재도전 목록에 넣습니다. 재도전은 그 문제들만 입력형으로 냅니다. 실제로 도움 없이 맞힌 경우에만 회복한 문제로 표시합니다. 빈칸이나 단어 하나를 문장 전체를 썼다고 계산하지 않습니다.

기본 정답 XP와 독립 회상 XP는 문항마다 한 번씩만 받습니다. 같은 실행 ID의 완료 결과를 다시 처리해도 보상·스탬프·기억 강도를 중복 반영하지 않습니다.

## 루의 방

완료한 문장 연습에서 하루 합계 **3·10·20문제를 달성할 때마다 스탬프 1개씩**, 최대 3개를 받습니다. 가게에서 1~8개로 소품을 구매하고 직접 배치합니다. 기존 날짜별 학습량에도 같은 적립 기준을 적용합니다. 연속으로 들어와야 한다는 조건이나 놓친 날의 손실은 없습니다.

| 3문제 이상 학습한 날 | 무료 선물 |
| --- | --- |
| 1일 | 작은 화분 |
| 3일 | 책 한 묶음 |
| 7일 | 포근한 러그 |

선물은 스탬프를 써도 보유합니다. 방 소품 33종 중 나머지 30종은 가게에서 구매하며, 한 번 산 소품은 여러 개 배치할 수 있습니다. 한 방에는 소품을 24개까지 놓습니다. 벽 6색·바닥 3종과 소품·루의 위치·크기·각도·반전을 조절합니다.

옷장에는 옷 12종·안경 8종·머리 장식 10종, 총 30종이 있습니다. 민트 구름 잠옷·항구의 줄무늬 티·모카 동그리 안경·데이지 핀은 기본 제공하고 나머지는 1~6개 스탬프로 구매합니다. 털 무늬 3종과 네 포즈를 고를 수 있으며 자동 포즈도 지원합니다.

목록은 6개씩 넘겨 봅니다. 구매 전에는 조합을 미리 보고, **저장**하면 차림과 배치를 홈·학습·인증 카드에 반영합니다. 편집 중 닫기를 누른 뒤 **계속 꾸미기**를 선택하면 펼쳐둔 배치 도구와 화면 위치를 복원합니다. 방이 가득 차 구매한 소품을 바로 놓을 수 없으면 **내 소품에 보관**했다고 안내합니다.

학습 달력은 목표 달성일을, 가게는 지출 후의 스탬프 잔액을 보여줍니다. 구매·기존 선물·과거 배치 이력의 도입 설계는 별도 기록에 있습니다. [v1.12 꾸미기 도입 기록](room-studio-1.12.md)

기존 학습 기록의 날짜도 반영합니다. 날짜별 기록은 최근 200판의 상세 기록과 별도로 유지합니다. 기초 표현 레슨은 기존 XP·연속 학습일에는 반영되며, 이 스탬프는 문장 연습의 완료 문항을 기준으로 합니다.

## 기록과 인증

월간 달력과 주간 기록은 일요일부터 표시합니다. 날짜 선택 시 그날의 상세 기록을 화면에 보여주고, 주간·누적 통계는 펼쳐 읽습니다. 인증 카드의 경험치는 **+20 XP / 경험치**처럼 표시하며, 해당 날짜까지 저장한 방과 차림을 담은 1080×1350 PNG를 생성합니다. 공유를 지원하는 기기에서는 **이미지 공유**도 제공합니다.

## 검증 범위와 후속 판단

v1.19.0에서 142개 자동 테스트로 기존 기능과 보강 문제의 저장·복습·보상을 확인했습니다. Chrome에서 보강 210문제를 모두 완료하고 320px·390px의 화면을 확인했습니다. 가로 화면·키보드 높이·꾸미기·인증 카드의 이전 검증은 v1.18.0 기록에 있습니다. 실제 휴대폰 키보드·스피커·설치·공유 동작은 후속 확인 대상입니다.

실제 사용자의 재방문율이나 완주율이 높아졌다고 검증한 것은 아닙니다. 현재 계정·서버·사용자 분석 수집은 없습니다. 콘텐츠는 입문 180문제와 중급 240문제로 구성하며 런타임 AI 생성이나 발음 평가는 하지 않습니다.
