# v1.12.0 · 루의 방 꾸미기와 스탬프 가게

2026년 11월 13일 GitHub Pages 공개 배포 완료. [배포 기록](https://github.com/sidebatch/french-alone/actions/runs/43550920510)

## 바뀐 학습 인증 카드

- 누적 스탬프 문구를 제거했습니다.
- 경험치는 **+20 XP / 경험치**처럼 짧게 표시합니다. 실제 획득량이 0이면 +0 XP입니다.
- 저장한 방의 소품·배치·벽·바닥·루의 위치를 인증 이미지에도 그립니다. 미리보기와 내려받는 PNG는 동일합니다.
- 과거 날짜에는 그날 또는 그 이전의 마지막 저장 배치를 사용합니다. 저장 이력이 없으면 그날까지 받은 기본 선물로 방을 구성합니다. 미래에 구매한 소품은 과거 기록에 넣지 않습니다.

## 방 꾸미기

홈의 **방 꾸미기 · 소품 가게**에서 엽니다.

- 소품과 루를 마우스 또는 손가락으로 옮깁니다. 키보드 화살표와 화면의 이동 버튼도 지원합니다.
- 크기 60~160%, 각도 -30~30도, 좌우 반전, 소품끼리 앞뒤 순서를 조절합니다. 루는 소품보다 앞에 표시됩니다.
- 벽 6색과 바닥 3종은 무료로 바꿉니다.
- 한 방에 소품 24개를 놓을 수 있습니다. 구매한 디자인은 추가 차감 없이 여러 개 배치합니다.
- **보관함으로**는 배치만 해제합니다. 구매 이력·보유 권한은 유지합니다.
- 구매 전에 소품을 방에 미리 놓고 위치·크기를 바꿔 볼 수 있습니다. 소품 구매는 가격이 표시된 버튼을 눌러야 실행됩니다.
- **배치 저장** 후 홈·인증 카드에 반영됩니다. 편집 중 닫으려 하면 변경분을 버릴지 확인합니다. 배치를 취소해도 구매한 소품은 보관함에 남습니다.

## 스탬프와 목표

| 하루에 마친 문장 연습 | 이날 적립되는 스탬프 합계 |
| --- | ---: |
| 0~2문제 | 0개 |
| 3~9문제 | 1개 |
| 10~19문제 | 2개 |
| 20문제 이상 | 3개 |

- 3·10·20문제 목표마다 하나씩, 하루 최대 3개입니다. 완료한 판의 문제 수를 사용하며 같은 판을 중복 처리해도 추가 적립되지 않습니다.
- 기존 날짜별 문장 연습 기록에도 같은 기준을 적용합니다. 기존 스탬프를 없애지 않고, 10·20문제를 풀었던 날에는 추가분도 반영합니다.
- **보유 스탬프 = 누적 적립량 − 실제 구매 당시 지불한 스탬프 합계**입니다. 구매가 학습일·연속 기록·XP를 줄이지 않습니다.
- 기초 표현 퀴즈는 기존처럼 경험치와 학습 기록에 반영하며, 방 꾸미기 스탬프의 기준은 문장 연습입니다.
- 달력의 체크는 하루 3문제 이상 마친 **목표 달성일**입니다. 가게의 사용 가능한 스탬프 잔액과 혼동하지 않도록 학습일로 표시합니다.
- 연속 출석을 놓쳐도 소품이나 스탬프가 사라지지 않습니다. 원하는 소품을 목표로 고르면 홈에서 필요한 스탬프와 남은 수량을 봅니다.

## 소품 27종

기존 화분·책·러그 3종은 문장 연습 목표 달성 1·3·7일의 무료 선물로 보존합니다. 나머지 24종은 1~8개 스탬프로 구매합니다.

| 분류 | 소품 |
| --- | --- |
| 식물 | 작은 화분, 살구빛 튤립, 동글 선인장 |
| 가구 | 티 테이블, 안락의자, 책장, 창가 책상, 푸프, 나무 놀이터, 수납장, 소파, 벽난로 |
| 조명 | 버섯 스탠드, 별빛 전구 |
| 벽 장식 | 꽃 액자, 벽시계, 가랜드, 파리 포스터 |
| 소품 | 책, 레몬 쿠션, 따뜻한 차, 담요 바구니, 턴테이블, 이젤, 어항 |
| 러그 | 포근한 러그, 푸른 원형 러그 |

소품은 코드로 그린 로컬 SVG입니다. 기존 루 이미지를 재사용하며, 별도 API나 네트워크 이미지 생성 없이 오프라인으로 제공합니다.

## 저장과 보호

- 새 저장 키 `bonjour-room-v1`에 구매 당시 가격·날짜, 보유 선물, 현재 배치, 날짜별 배치 이력과 목표를 저장합니다. 기존 학습 키와 ID는 유지합니다.
- 소품 구매는 최신 저장 기록을 읽은 뒤 잔액과 보유 여부를 다시 확인합니다. Web Locks 지원 브라우저에서는 탭 사이 구매도 직렬로 처리합니다.
- 다른 창에서 배치를 변경했다면 오래된 편집으로 덮어쓰지 않고 다시 열도록 안내합니다.
- 없는 소품·미보유 소품·중복 배치 ID를 걸러내고 위치·크기·각도·배치 수를 제한합니다.
- 저장 공간 오류 시 이번 방문 동안의 상태를 유지하고 안내합니다. 저장 실패를 저장 성공으로 표시하며 닫지 않습니다.
- 전체 학습 기록 초기화에는 구매·방 배치도 포함됩니다. 계정 동기화와 서버 백업은 없습니다.

## 검증

- 전체 **121개 테스트 통과**. 새 12개 검사는 일별 적립 상한, 기존 선물 보존, 중복 차감·잔액 부족, 재사용, 배치·과거 이력, 손상 데이터, 저장 실패와 다른 창의 변경을 다룹니다.
- Chrome 320·390·768·1440px에서 편집 화면의 가로 넘침과 배치를 확인했습니다.
- 실제 브라우저에서 구매 → 드래그·키보드 이동 → 저장 → 새로 열기 → 취소 흐름, 목표 설정을 확인했습니다.
- 터치 에뮬레이션으로 루를 드래그하고 저장했습니다. 실제 Android/iPhone 손가락 조작은 별도 검증이 필요합니다.
- 오프라인으로 다시 열어 가게 구매·방 저장·인증 PNG 생성이 되는지 확인했습니다.
- 실제 1080×1350 PNG에서 짧아진 경험치 문구, 누적 스탬프 제거와 꾸민 방을 확인했습니다.
