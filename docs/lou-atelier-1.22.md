# 루의 아틀리에 · v1.22.0

2026년 11월 21일. 루의 포근한 인상을 유지하면서 의상·장식·방의 시각적 완성도와 옷장 감상 경험을 다듬었습니다.

## 적용 내용

- 기본 루와 기존 옷 12벌을 동일한 기본 이미지에서 새로 제작했습니다. 각각 손인사·방긋·갸웃·만세 네 포즈를 포함합니다. 얼굴 위치와 비율을 유지하고 윤곽, 털, 모자·스카프의 바느질, 옷의 어깨·소매·주름과 명암을 정리했습니다.
- 8종 안경과 10종 머리 장식에 공통 접촉 그림자를 적용하고 기본 동그리 안경의 렌즈 반사광을 다듬었습니다. 장식은 기존 포즈별 위치를 유지합니다.
- 방은 벽의 은은한 명암, 몰딩, 창틀 두께와 그림자, 유리 반사, 바닥 명암을 추가했습니다. 33종 소품에는 공통 가장자리 빛과 그림자를 적용합니다. 화면과 인증 카드가 같은 그림을 사용합니다.
- 옷장은 가운데 무대에서 루를 크게 보여 줍니다. **크게 보기**는 목록을 잠시 숨기고 **목록으로** 또는 Escape로 돌아갑니다. 아주 작은 화면에서는 가로 배치로 높이를 줄이며, 필요한 스크롤은 대화상자 하나에서만 발생합니다.
- 옷장 속 루를 누르면 잠시 방긋 웃고 인사합니다. 이 반응은 저장한 포즈를 바꾸지 않습니다. 반복해서 눌러도 이전 타이머는 취소되며 화면을 닫거나 변경하면 정리합니다. 동작 줄이기 설정에서는 확대·흔들림 애니메이션을 끕니다.

## 자산과 유지보수

- 기본 이미지: `dist/assets/lou-sprites-v3.webp`.
- 옷: `dist/assets/lou-outfits-v3/<id>.webp`, 썸네일: `<id>-thumb.webp`.
- 13개 시트는 1024×1024, 썸네일은 160×160입니다. WebP로 압축하며 생성된 투명도를 보존했습니다. 니트·멜빵바지·우비·줄무늬 티는 배경 경계를 한 번 더 정리했습니다.
- 제작은 내장 ImageGen을 사용했습니다. [최종 프롬프트 모음](assets/lou-v3-prompts.json)에 기본 이미지와 옷별 요청, 추가 배경 정리 요청을 기록했습니다. Sharp는 배포 크기 조정·WebP 변환·첫 포즈 썸네일 추출에만 사용했습니다.
- 원래 파일은 보존하고 새 경로를 사용합니다. 새 시트·썸네일·`atelier.css`는 오프라인 캐시에 포함합니다.
- 아이템 ID, 가격, 보유 내역, 방 배치와 다섯 기록 키는 바꾸지 않았습니다. 이전 백업에서 복원한 차림도 새 그림으로 표시됩니다. 자동 백업 방식은 v1.21과 같습니다.

## 검증

[v1.22.0 공개 배포](https://github.com/sidebatch/french-alone/actions/runs/44936343237)가 성공했습니다. 공개 주소에서도 아래 네 화면 크기, 확대·인사·차림 저장·오프라인 재실행·인증 카드용 그림을 다시 확인했습니다.

- 자동 검사 189개 통과, 구문 검사 37개 통과.
- 320×640, 390×844, 768×1024, 844×390 Chrome 화면에서 가로 넘침 없이 표시됨. 기본 옷장 기준 390px와 768px에서는 스크롤 없이 표시됩니다. 320px와 가로로 짧은 화면은 한 영역에서 필요한 만큼 스크롤합니다. 긴 설명·구매 미리보기에서는 높이가 추가될 수 있습니다.
- 확대 보기, Escape 복귀와 초점, 구매 불가 상태 유지, 인사 반응과 저장 포즈 분리, 기존 테스트 기록 복원, 무료 의상·안경 저장 후 오프라인 재실행, 인증 카드용 방 그리기 확인.
- 기본 루와 12벌 × 네 포즈를 어두운 배경 위에서 안경·꽃핀과 함께 확인했습니다. 브라우저 실행 오류 없음.
- 실제 Android 기기에서의 촉감·속도·사용성은 아직 직접 확인하지 않았습니다. 새 이미지들은 2D 시트이며 입체 회전이나 관절별 애니메이션은 제공하지 않습니다.

앞으로 새 의상을 추가할 때도 동일한 얼굴·광원·네 포즈와 투명 경계 기준을 유지하고, 작은 화면에서 차림이 구별되는지 확인합니다.
