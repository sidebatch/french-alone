# Lou mascot — 1.3.1

App asset: `dist/assets/lou-sprites-v2.webp` (losslessly encoded from the generated PNG for a smaller download).

Original asset: `docs/assets/lou-sprites-v2-source.png` (transparent PNG; original generated pixels preserved).

Created with the built-in ImageGen tool, with transparent_background set to true. No CLI/API fallback was used.

One shared sheet serves four UI poses without additional image requests: top left greeting, top right delight, bottom left thinking, bottom right celebration. CSS selects the relevant cell. The image is preloaded and included in the app's offline cache. Decorative poses are hidden from assistive technology; encouragement remains real text.

## Final generation prompt

Use case: stylized-concept. Asset type: production mascot sprite sheet for the French Alone mobile French learning app. Create a polished, exceptionally cute original cream kitten named Lou, rendered as a premium soft 3D clay/plush character, with a huge rounded head (about 60% of height), tiny rounded ears, short chubby body and stubby paws, round shiny dark chocolate eyes with little highlights, tiny inverted triangle rose nose, small smiling mouth, rosy peach cheeks. A small sage-green French beret, a simple muted terracotta neck scarf, cream fur; no shirt, no stripes. Friendly, collectible toy silhouette, gentle studio lighting, soft ambient occlusion, subtle velvet texture, restrained sophisticated palette. Must look like a finished beloved app character, beautifully modeled and expressive, not generic clip art and not line-drawn SVG. Output ONE SQUARE TRANSPARENT PNG SPRITE SHEET with precisely FOUR equally sized square cells in a strict 2 by 2 grid, each cell exactly one quarter of total image. No borders or visible grid. Every cell has the SAME identical character, whole body fully visible, centered at the same scale, occupying 80% of cell with generous transparent margins so no part crosses its cell boundary. Top left: open-eyed warm smile, one tiny paw raised greeting the viewer. Top right: joyful eyes closed into upward crescents, chubby paws together excitedly, delighted expression. Bottom left: adorable thoughtful head tilt, one paw against cheek, reassuring slight smile, curious eyes, never sad or distressed. Bottom right: both little arms raised in celebration, happy crescent eyes, open smiling mouth, three tiny warm gold sparkles beside head contained in its cell. Keep exact same face, beret, scarf, lighting, proportions and framing between the four poses. True transparent alpha background in every cell, no painted white background, no checkerboard, no scenery, no text, no labels, no letters, no watermark. Soft small contact shadow beneath each character only. Crisp edges suitable for 48px UI avatars and 180px hero use.
