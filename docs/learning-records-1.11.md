# v1.11.0 · 학습 인증 카드와 월간 달력

2026년 11월 13일 로컬 구현. 공개 배포에는 아직 반영하지 않았습니다.

이 문서는 v1.11 당시의 기록입니다. v1.12에서 인증 카드 누적 스탬프 제거·경험치 문구 단축·자유 배치한 방 반영과 스탬프 적립 변경을 적용했습니다. [현재 동작](room-studio-1.12.md)

## 사용 흐름

- **학습 기록 → 나의 학습 달력**에서 월을 이동하고 날짜를 선택합니다. 월별 학습일·스탬프·기록된 문제 수·XP, 날짜별 문장 연습·기초 퀴즈 문제 수를 봅니다.
- **오늘 학습 인증** 또는 **이날의 인증 카드**로 날짜·학습량·경험치·연속 학습일·루의 방을 담은 카드를 엽니다. 홈과 문장 연습·기초 퀴즈 완료 화면에서도 바로 열 수 있습니다.
- **이미지 저장**은 미리보기와 같은 1080×1350 PNG를 내려받습니다. 파일 공유를 지원하는 기기에는 **이미지 공유**도 표시합니다. 공유 창은 버튼을 눌렀을 때만 엽니다.
- 날짜와 달은 기기의 현지 날짜를 사용합니다. 미래 날짜와 기록 없는 날짜에는 인증 카드를 만들지 않습니다. 화살표 키·Home·End로 달력의 날짜를 이동할 수 있습니다.
- 인증 카드를 닫으면 열기 전 화면과 버튼으로 돌아갑니다. 학습 완료 기록·진도·XP를 다시 지급하지 않습니다.

## 집계와 기존 기록 보존

- 기존 저장 키와 문제 ID를 유지합니다. `bonjour-french-v1.activity`의 XP는 이미 문장 연습 보상을 포함하므로 다시 더하지 않습니다.
- 문장 연습은 `bonjour-practice-v1.days`에 누적된 완료 문제 수와 한 판 수를 사용합니다. 최근 200판 기록이 잘려도 날짜별 합계는 남습니다.
- 기초 퀴즈는 완료 시 `basicQuestions`와 `basicRounds`를 추가로 저장합니다. 실패한 퀴즈와 보상을 이미 받은 반복 퀴즈도 실제로 마친 문제 수에 포함합니다. 중간에 멈춘 문제는 완료 기록에 포함하지 않습니다.
- 이전 버전에는 기초 퀴즈의 날짜별 문제 수가 없습니다. 과거 XP에서 문제 수를 역산하지 않고 **기록된 문제**로 표시하며, 누락된 기초 문제 수를 안내합니다. 같은 날 업데이트 전후 기록이 섞이면 `basicCountPartial`로 구분합니다.
- 문장 연습 하루 3문제에 스탬프 1개라는 기존 규칙을 유지합니다. 기초 퀴즈는 이 스탬프를 지급하지 않습니다.
- 과거 인증 카드의 연속 학습일은 선택한 날짜에서 거슬러 계산합니다. 루의 화분·책·러그는 해당 날짜까지 얻은 스탬프 1·3·7개에 맞춰 그립니다. 나중에 얻은 소품을 과거 카드에 표시하지 않습니다.
- 기록과 인증 이미지를 서버에 전송하지 않습니다. 카드 이미지는 브라우저에서 생성하고, 저장·공유는 사용자가 선택합니다. 카드 생성 자체에는 별도 저장 권한이나 AI 호출이 필요하지 않습니다.

## 파일

- `records-core.js`: 달력 날짜, 기록 합산, 월별 합계, 날짜별 연속 학습과 누적 스탬프.
- `records.js` / `records.css`: 달력·날짜별 상세·인증 팝업·이미지 저장과 파일 공유.
- `record-card.js`: 기존 루 이미지와 Canvas로 동일한 미리보기·PNG 생성.
- 새 모듈과 스타일은 서비스 워커의 오프라인 캐시에 포함합니다.

## 검증

- 단위·DOM 검사: 기존 기능 포함 **109개 테스트**. 새 10개 검사는 과거 기록, XP 중복 방지, 반복 퀴즈, 기록 200판 제한, 과거 스탬프, 윤년·연말, 키보드, 공유 취소·실패·대체 저장, 닫힌 카드의 비동기 처리 등을 확인합니다.
- Chrome 실제 렌더링: **320·390·768·1440px**에서 빈 달력·기록 있는 달력과 가로 넘침 확인.
- 실제 **1080×1350 PNG** 다운로드와 루·날짜·학습량 표시 확인. 과거 날짜 카드의 소품 수 확인.
- 새 브라우저에서 실제 3문제 완료 → 인증 카드 → Escape → 완료 화면 → 홈 → 달력 흐름을 확인하고, 카드 열람 전후 저장된 학습 기록이 같은지 비교합니다.
- 서비스 워커가 제어하는 페이지를 오프라인으로 다시 연 뒤 인증 카드 생성 확인.
- 실제 Android/iPhone의 공유 대상 앱 선택, 사진 앱 저장 동작은 아직 실기기에서 검증하지 않았습니다. 공유를 지원하지 않거나 실패하면 이미지 저장을 사용합니다.
