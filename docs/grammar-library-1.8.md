# v1.8.0 문법 도서관

현재 입문·중급 21코스의 210문제와 114개 짧은 레슨을 32개 상세 문법 항목으로 연결했습니다. 프랑스어 문법 전체를 완결한 사전이라는 뜻은 아닙니다. 전문적인 원어민 감수와 실제 iOS/Android 기기 시험을 대신하지 않습니다.

## 학습 화면과 도서관

- 문제에서는 기존의 짧은 해설을 보고, `조금 더 알아보기`에서 해당 문제의 형태·예문을 읽습니다. 그 아래 `문법 보기`를 누르면 관련 상세 항목이 열립니다.
- 상세 카드는 별도의 모달입니다. 문제를 다시 그리거나 학습을 종료하지 않으므로 입력 내용, 선택한 카드, 펼친 설명, 스크롤, 진행 상태가 유지됩니다. 닫기와 Escape로 돌아갑니다. 키보드 Tab은 카드 안에서 순환합니다.
- 하단 `문법` 탭에서 검색과 네 가지 분류를 사용할 수 있습니다. 원형·불규칙 활용형·한국어 별칭과 실제 설명 내용을 검색합니다. 프랑스어 악센트와 대소문자는 구분하지 않으며, `y`, `en`, `vu`처럼 짧은 프랑스어 검색은 단어 단위로 처리합니다.
- 상세 항목은 설명, 활용표, 번역이 있는 예문, 혼동과 예외를 포함합니다. 기존 짧은 레슨의 활용표는 같은 원본을 재사용하고, 더 넓은 규칙과 추가 표·예문을 보충했습니다.

## 항목 목록

| 분류 | 항목 |
| --- | --- |
| 문장의 기본 | 동사원형, 부정문, 명사와 관사, 형용사의 성·수 일치, 장소와 방향, 위치와 질문 |
| 동사와 표현 | être, avoir, aller, vouloir, pouvoir, aimer, 정중한 요청, 필요한 것과 행동, 배고픔·갈증·더위·추위 |
| 시제와 가정 | 복합과거, 과거분사와 불규칙형, être를 쓰는 과거와 일치, 과거 부정문, 반과거, 반과거와 복합과거 비교, 단순미래, 가능한 조건, 가정과 조건법 현재 |
| 대명사와 연결 | 목적어 대명사, y, en, 관계절, 비교와 meilleur·mieux, 이유·결과·대조, 생각과 판단, 필요와 바람의 접속법 |

대표 연결: `past-events-3`(voir의 과거분사) → 과거분사와 불규칙형, `past-events-5`(n’ai pas vu) → 과거 부정문, `past-movement-3`(arrivée) → être를 쓰는 과거와 일치. 모든 연결은 `grammar-data.js`의 각 항목 `lessonIds`에서 관리하며, 누락·중복은 자동 검사에서 실패합니다.

## 개인 열람 기록

- `bonjour-grammar-v1`에 항목별 누적 횟수를 저장합니다. 기존 학습·XP·단어장 기록과 분리합니다. 계정이나 공개 조회수는 없습니다.
- 문법 탭에서는 카드를 새로 열 때 1회 증가합니다. 문제에서는 동일한 학습 회차·동일한 문제·동일한 항목을 여러 번 열어도 1회로 세며, 앱을 다시 열어 이어 풀어도 중복 계산하지 않습니다.
- 최근 512개 문제 열람 맥락만 보관하며 누적 횟수는 유지합니다. 이미 열린 카드에 대한 중복 동작은 증가시키지 않습니다.
- 같은 기기의 다른 탭이 저장한 값을 다음 열람 전에 다시 읽습니다. 저장이 불가능하면 현재 방문 동안 기록을 유지하고 한 번 알립니다. 모든 학습 기록 초기화에는 문법 열람 기록도 포함됩니다.
- 열람 횟수는 눈 아이콘과 숫자만 표시합니다. 마지막 확인일·약점 판정·학습 점수를 추가하지 않습니다. 정답 전에 해설을 읽은 문제는 기존 도움받은 풀이 규칙을 따릅니다.

## 검증

- 자동 검사 86개 통과: 114개 짧은 레슨의 고유 연결, 210문제에서 상세 카드 열고 닫기, 점수·보상 회귀, 대표 활용형·한국어 검색, 손상된 저장값, 개인 횟수·중복 방지·초기화, 입력/배열/초점/스크롤 복귀.
- Chrome에서 32개 항목을 320·390·768·1440px 너비로 열어 총 128개 레이아웃을 확인했습니다. 표·본문의 가로 넘침, 끝까지 스크롤, 닫기 버튼 접근, Tab 순환과 Escape, 모바일 5개 탭을 검사했습니다.
- 실제 브라우저 학습 흐름에서 문제별 문법 연결과 원래 화면 복귀를 확인했습니다. 오답 입력 `vois`, 선택 범위, 열린 설명, 스크롤, 학습 기록이 그대로 유지됩니다.
- 서비스 워커에 네 개 새 파일을 포함했습니다. 온라인으로 한 번 로드한 뒤 네트워크를 차단하고 재실행해 문법 검색·과거분사 카드와 중급 학습을 확인했습니다.
