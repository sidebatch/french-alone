# 루의 방·옷장·상점 인터페이스 · v1.23.0

2026-11-23. 기존 루와 아이템을 살리면서, 비슷한 테두리 상자가 반복되던 화면의 정보 순서와 조작을 정리했습니다. 이미지는 v1.22 자산을 그대로 사용합니다.

## 화면 구성

- 상단의 **내 방·옷장·상점·인테리어** 메뉴, 보유 스탬프와 저장 버튼을 고정합니다. 선택한 메뉴는 아이콘·글자색·밑줄로 표시합니다.
- 휴대폰에서는 화면 전체를 사용합니다. 넓은 화면에서는 미리보기와 목록을 나란히 둡니다. 스크롤은 꾸미기 화면 하나에서만 일어납니다.
- 상품은 그림을 먼저 보여주고 이름과 가격을 아래에 둡니다. 가격은 황금색 스탬프, 보유는 글자, 착용은 초록색 표시로 구분합니다. 선택한 상품 그림에는 테두리를 표시합니다.
- 상품 목록은 6개씩 표시하고 페이지 이동을 목록 아래에 둡니다. 비어 있는 소품 목록에는 상점으로 가는 버튼을 제공합니다.
- 옷장에는 **내 것만** 필터를 추가했습니다. 큰 미리보기 옆의 옷·안경·머리 장식 버튼으로 해당 분류를 바로 엽니다. 짧은 휴대폰 화면에서는 이 바로가기를 숨기고 아래 분류 버튼을 사용합니다.
- 높이 760px 이하의 휴대폰에서는 루와 현재 차림을 나란히 배치합니다. 크게 보기에서는 목록을 숨기고 루를 확대합니다.
- 상점에서는 방 미리보기 크기를 줄여 상품을 더 일찍 보여줍니다. 소품을 고르면 구매·배치 안내를 표시합니다. 벽과 바닥은 색 견본으로 선택합니다.

## 동작과 기존 기록

필터와 분류 변경은 스탬프를 쓰거나 착용을 저장하지 않습니다. 보유하지 않은 옷은 미리 입은 뒤 구매 버튼으로 확정하고, 잔액이 부족하면 구매할 수 없습니다. 미리 입기 상태에서 저장하면 구매하지 않은 옷은 저장 대상에서 제외됩니다.

기존 아이템 ID, 가격, 구매·배치 이력, 저장 키와 기록 형식은 바꾸지 않았습니다. 저장한 차림·벽·소품 배치는 다시 열거나 오프라인으로 실행해도 읽습니다. 기록 백업은 기존 v1.20·v1.21 기능을 계속 사용하며, 이번 변경이 이미 사라진 기록을 복구하는 것은 아닙니다.

## 검증

- 전체 자동 테스트 **191개** 통과. 보유 필터의 미리보기·구매 분리와 착용 부위 이동을 추가 확인했습니다. 마지막 화면 조정 후 방 관련 **22개**를 다시 통과했습니다.
- 앱·지원 스크립트 **37개**의 구문 검사 통과.
- Chrome의 320×640, 360×740, 390×844, 768×1024, 1440×900, 844×390 화면을 확인했습니다. 가로 넘침·중첩 스크롤·실행 오류가 없었습니다.
- 옷장의 보유 필터, 무료 옷·안경 착용, 확대와 Escape 복귀, 인사, 잔액 부족 시 구매 제한을 확인했습니다.
- 소품 분류·미리보기·구매, 벽 변경·반전·저장, 빈 보관함에서 상점으로 이동을 확인했습니다.
- 테스트 기록에서 스탬프 5개 중 1개로 튤립을 구매한 뒤, 인터넷을 끄고 다시 실행해 잔액 4개·구매 소품·옷·안경·벽 색이 유지됨을 확인했습니다.

옷장 기본 화면은 위 세로 화면에서 스크롤 없이 표시됩니다. 390×844에서는 상점·인테리어 기본 화면도 맞습니다. 구매 설명·배치 도구를 펼치거나 낮은 가로 화면에서 사용하는 경우에는 하나의 세로 스크롤을 허용합니다. 모든 화면에서 스크롤을 없애는 것이 목표는 아닙니다.

검증은 격리된 Chrome과 테스트 기록으로 진행했습니다. 실제 Android 설치 앱, 사용자의 기존 기록, 확대 글꼴과 보조 기술의 모든 조합을 확인한 것은 아닙니다.
