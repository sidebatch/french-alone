# French Alone 진행 현황

기준일: **2026년 11월 13일** · 공개 앱 버전 **v1.12.0**

학습 인증·월간 달력에 이어 소품 27종·스탬프 가게·자유 배치를 공개 앱에 배포하고 검증했습니다. 인증 카드의 누적 스탬프를 제거하고 경험치 문구도 줄였습니다. 공개 주소에서 3문제 완주, 스탬프 구매, 방 저장 복원, 달력과 인증 PNG 다운로드를 확인했습니다. [v1.12 구현·보상·검증 범위](room-studio-1.12.md)

채팅 없이도 현재 작업을 파악하고 이어갈 수 있도록 작성한 기준 문서입니다. 완료 여부는 실제 코드·콘텐츠와 확인된 배포 결과로 구분했습니다. 논의하거나 요청한 아이디어만으로 완료 처리하지 않았습니다.

## 1. 현재 상태

French Alone은 로그인 없이 사용하는 한국어 사용자용 프랑스어 학습 웹앱입니다. 입문·중급의 짧은 텍스트 문제와 독립적으로 검색하는 문법 도서관을 제공하며 공개 배포되어 있습니다.

## 2. 유지할 제품 방향

1. 음성 문제 없이 타이핑과 문장 배열로 반복 학습한다.
2. 앱 사용법 설명은 짧게 유지하고, 필요한 분량은 프랑스어 설명에 쓴다.
3. 한 번에 3~5문제로 시작하고 복습·재도전으로 학습을 이어 간다.
4. 해설은 **짧은 답 설명 → 조금 더 알아보기 → 문법 보기** 순서로 깊어진다.
5. 문법 도서관은 현재 문제 범위와 독립적으로 확장한다. 나중에 만드는 문제에서도 연결한다.
6. 문법 용어에는 한국어와 프랑스어를 함께 표시한다.
7. 루와 학습 기록으로 매일의 성취를 보여 준다. 실제 재방문율 향상 여부는 별도 검증이 필요하다.

## 3. 완료된 기능

### 학습·복습·채점

- 오늘의 5문제, 가벼운 3문제, 코스별 10문제 학습.
- 입문·중급 선택과 수준별 추천·복습·이어하기.
- 복습할 문제와 새 문제를 섞어 제공. 직접 회상한 정답에 따라 1·3·7·14일 복습 간격 적용.
- 힌트·정답 보기·오답·카드 도움을 사용한 문제만 다시 도전.
- 글자·패턴 힌트, 악센트 입력 키, 글자·단어 카드 도움.
- 정답·오답 안내는 짧게 표시하고 자세한 해설은 사용자가 열어봄.
- 대소문자·공백·문장 끝 부호·아포스트로피 형태 처리. 악센트 오류는 별도 안내.
- 문제별 허용 답안 지원. 모든 자유 작문·의역을 이해하는 채점 기능은 아님.
- 입력한 글·배열한 카드·힌트·진행 위치를 저장해 복귀.
- 힌트 없이 맞힌 답과 도움받은 답을 구분. 같은 완료 기록의 중복 보상 방지.

### 기초 표현·단어장

- 프랑스어 표현의 뜻·발음·용법 확인.
- 기초 레슨별 퀴즈, 진행률·완료 상태, 틀린 표현 복습.
- 표현 검색, 즐겨찾기, 상세 카드, 뒤집는 복습 카드.
- 일반·느린 발음 듣기. 발음 평가나 듣기만으로 답해야 하는 문제는 없음.

### 문법 도서관

- 별도 **문법 탭**, 분류와 검색.
- 한국어·프랑스어 용어, 동사 원형·활용형으로 검색.
- 규칙·활용표·예외·프랑스어 예문·한국어 번역 제공.
- 문제에서 관련 문법을 스크롤 가능한 카드로 열고, 닫으면 원래 문제로 복귀.
- 답안·배열·스크롤·펼친 설명 상태 유지.
- 개인 열람 횟수를 **눈 아이콘 + 숫자**로 표시.
- 같은 풀이의 같은 문제에서 같은 문법을 반복해서 열면 중복 집계하지 않음. 도서관에서 다시 열면 새 열람으로 집계.
- 새 문제에서 문법 한 개 또는 여러 개를 직접 연결할 수 있게 구성.
- 문법 파일도 오프라인으로 제공.

### 화면·루·효과음·학습 기록

- 휴대폰 전체 화면 학습과 키보드가 열린 높이에 맞춘 입력 화면.
- 주요 버튼 크기, 글자·카드·설정 화면 정리. 키보드 접근과 모션 줄이기 지원.
- 베레모 고양이 **루(Lou)**의 인사·기쁨·생각·축하 표정.
- 정답·재도전·완료 효과음, 음량 조절과 미리 듣기.
- 연속 학습일, XP, 주간 학습 기록.
- 하루 문장 연습 3·10·20문제 달성마다 스탬프 1개씩, 최대 3개 적립. 기존 날짜별 기록도 반영.
- 학습 1·3·7일의 화분·책·러그 선물 보존. 소품 27종, 스탬프 구매, 여러 개 배치, 이동·크기·각도·반전·순서, 벽·바닥 변경과 저장.
- 보유 스탬프에서 구매 비용만 차감하며 학습일과 XP는 유지. 원하는 소품을 목표로 설정.

### 학습 인증·월간 달력 — v1.11.0 로컬 완료

- 월 이동과 날짜 선택, 월별 학습일·스탬프·기록된 문제 수·XP.
- 날짜별 문장 연습·기초 퀴즈 완료 문제 수, 해당 날짜의 연속 학습일과 누적 스탬프.
- 홈·학습 완료 화면·달력에서 인증 카드 열기. 닫을 때 이전 화면과 버튼으로 복귀.
- 날짜·학습량·루의 방을 담은 1080×1350 PNG 저장 및 지원 기기에서 명시적인 파일 공유.
- v1.12에서 인증 카드 누적 스탬프를 제거하고 **+20 XP / 경험치**로 표시. 저장한 방을 반영하며 과거 날짜는 당시 배치 이력을 사용. 기초 퀴즈의 과거 문제 수는 추정하지 않음.
- 오프라인 생성, 공유 미지원·취소·실패와 이미지 생성 재시도 처리.

### 설치·배포·기록 보호

- GitHub Pages 공개 배포와 자동 검사 연결.
- 앱 설치 안내, 오프라인 저장, 새 버전 안내.
- 학습 중 강제 새로고침 없이 사용자가 새 버전 적용 시점을 선택.
- 기존 문제 ID와 저장 형식을 유지하며 진도·XP·초안·문법 조회수 보존.

## 5. 문법 확장·전수 검수의 범위

문법 도서관은 32개 → 67개 → 126개로 확장했습니다. 최신 추가 59개에는 사역구문, 동사와 전치사, 과거분사 일치의 예외, ce qui·ce que·ce dont, 숫자·날짜, 고급 연결 표현, 원형 과거, 접속법 반과거·대과거, 문어체 시제, 자유간접화법 등이 포함됩니다.

참고서·교재 3종의 공개 목차에서 **97개 문법 단원**을 확인하고 앱 항목과 대조했습니다. 한국어 설명과 예문은 앱용으로 새로 작성했습니다.

**확인한 목차의 주요 주제에 대응하는 내용을 갖춘 상태입니다. 개별 문법책 본문의 모든 세부 예외까지 동일한 깊이로 전수 검증한 상태는 아닙니다.** 자동 검사도 언어 설명의 완전성이나 무오류를 보증하지 않습니다.

## 8. 권장 후속 작업 순서

학습 인증·월간 기록·루의 방 자유 꾸미기와 스탬프 가게는 공개 배포와 검증을 완료했습니다. 후속 순서는 다음과 같습니다.

1. **문제 추가**: 새 문법을 단어·문장 타이핑과 배열 문제로 연결. 짧은 해설·미니 레슨도 함께 작성.
2. **언어 내용 재검토**: 세부 예외·정답 대안·부자연스러운 번역과 설명을 점검.
3. **실기기 점검·사용성 관찰**: 인증 이미지 공유·휴대폰 입력·설치·효과음과 한 판 완료·다음 날 재방문 흐름 확인.

### 학습 콘텐츠와 재방문을 위한 할 일 (2026-11-14)

v1.12.1의 문장 연습 21코스에는 210문항이 있다. 첫 출제 형식은 선택 42개, 빈칸 입력 66개, 배열 42개, 단어·활용형 입력 18개, 문장 전체 입력 42개다. 전체 입력 42개 중 18개는 같은 코스 앞에서 이미 본 완성 문장을 다시 쓴다. 이 수치는 기초 표현 퀴즈와 복습 중의 입력 전환을 제외한 값이다.

| 순서 | 할 일 | 학습자 화면에서 확인할 것 |
| --- | --- | --- |
| 1 | 짧은 판에도 내 말로 끝내는 문제 넣기 | 첫 3·5문제 판의 마지막에는 그날 배운 어휘로 자기 뜻에 맞는 한 문장을 써 본다. 막히면 힌트로 마칠 수 있다. |
| 2 | 생활 주제별로 새 상황과 허용 답안 작성 | 주문·장소 묻기·도움 요청부터, 같은 문법을 다른 대화에서 쓰게 한다. 첫 연습과 며칠 뒤 확인용 예문을 따로 준비한다. 한국어 단서, 목표 문법, 자연스러운 다른 답을 함께 검수한다. |
| 3 | 틀린 규칙을 다른 문장으로 다시 연습 | 예를 들어 *Elle est allé*라고 썼다면 일치를 설명하고, 다음 복습에서는 이미 배운 *arriver*로 *Elle est arrivée*를 떠올리게 한다. |
| 4 | 며칠 쉬고 돌아오는 학생의 첫 문제 준비 | 익숙한 한 문장으로 바로 시작하게 하고 힌트와 한 문제 뒤 종료를 제공한다. 스탬프나 방 소품을 얻은 날에는 직접 완성한 문장도 함께 볼 수 있게 한다. |
| 5 | 루의 말을 듣고 한마디 답하는 문제 추가 | 카페에서 루가 매장 이용인지 포장인지 묻고, 학생이 상황에 맞는 답을 입력한다. |
| 6 | 짧은 판의 학습 효과와 복귀 흐름 검증 | 며칠 쉬었다 돌아온 학생 중 첫 판을 마친 비율과, 일주일 뒤 처음 보는 문장을 첫 시도에 힌트 없이 쓴 비율을 따로 확인한다. |

한국어를 보고 쓰는 문항은 출제문만 읽고 프랑스어로 답해 본 뒤 모범 답안과 대조한다. 한국어 어순은 자연스럽게 쓰되, 누가 무엇을 했는지와 시간·수량·부정의 단서는 양쪽에서 맞춘다. 생략한 주어나 문맥 때문에 여러 답이 가능하면, 특정 형태를 연습하는 문항에는 짧은 조건을 표시하고 회화 문항에는 자연스러운 다른 답도 등록한다. 정답을 본 뒤 제공하는 해설에는 상황에 맞는 자연스러운 한국어 풀이를 덧붙일 수 있다.

v1.13.0에서 문장 연습 210문항에 루의 목표 안내를 넣었다. `past-background-4`는 ‘어제 여덟 시에 책을 읽고 있었어’에 맞춰 *un livre*를 포함하고, *Je lisais un livre hier à huit heures*처럼 시간을 뒤에 둔 답도 인정한다. 조건절의 위치를 바꾼 배열 등도 추가했다. 카페 주문과 미래 시제 등에서 등록한 다른 표현을 쓰면 뜻을 인정하고 목표 표현으로 다시 안내한다. 아직 등록하지 않은 자연스러운 답은 계속 검토한다.

`need-10`의 ‘뭐 좀’에는 *J’ai besoin de manger quelque chose*도 허용한다. `necessity-10`은 루가 *Je veux que*를 연습한다고 미리 알려 준다. 문법 확장은 직접·간접목적어로 쓰이는 *me/te/nous/vous*, 선택을 묻는 *lequel*, 제안하는 *Et si on… ?*을 먼저 문항과 연결한다.
