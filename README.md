## 홈 화면에 앱으로 설치하기 (PWA)

앱을 연 뒤 상단의 **앱 설치**를 누르면 기기에 맞는 설치 방법을 볼 수 있습니다.

- **안드로이드 Chrome:** 앱 설치 버튼에서 설치 창을 열거나, 브라우저의 **⋮ → 앱 설치 / 홈 화면에 추가**를 선택합니다.
- **아이폰 Safari:** **공유 → 홈 화면에 추가 → 추가**를 선택합니다.
- 설치 메뉴가 보이지 않으면 앱 안의 주소 복사 기능으로 주소를 복사해 Chrome 또는 Safari에서 다시 엽니다.

최초 온라인 접속에서 오프라인 준비가 완료되면 짧은 한 판, 코스와 단어장을 인터넷 없이 열 수 있습니다. 발음 재생은 운영체제의 프랑스어 음성과 네트워크 지원에 따라 달라집니다. 학습 기록은 해당 브라우저/설치 앱의 저장 공간에 보관합니다.

업데이트는 온라인 접속 때 받아옵니다. 대기 중인 새 앱 버전이 있으면 학습을 마친 뒤 **새로 열기**로 적용할 수 있으며, 학습 중 강제로 새로고침하지 않습니다. 다른 GitHub Pages 저장소의 캐시는 건드리지 않습니다.

설치 방법 참고: [MDN 웹앱 설치 안내](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Installing).

## 기능

- **수준별 문장 연습**: 입문 9코스·90문제와 중급 12코스·120문제. 코스별 10문제 또는 3·5문제 한 판으로 연습
- 짧은 예문 → 빈칸 직접 입력·단어 배열 → 선택지 없이 문장 쓰기 → 새 동사로 조합하기
- 단계별 글자·패턴 힌트, 소리 힌트, 정답을 보고 연결하기
- 힌트 없이 첫 시도에 직접 쓴 정답과 도움받은 정답을 구분하는 결과 화면
- 내일부터 돌아오는 복습 문제: 독립 정답에 따라 1·3·7·14일 간격으로 조정
- 12개 기초 레슨, 프랑스어·한국어 뜻·한글 발음 안내가 있는 72개 표현
- 표현 익히기 → 6문제 무작위 객관식 퀴즈 → 결과 확인 (5개 이상 정답이면 완료)
- 브라우저 Web Speech API를 이용한 프랑스어 발음 듣기와 느리게 듣기
- 표현 검색, 즐겨찾기 단어장, 오답 모음과 뒤집는 복습 카드
- 한 판만 마쳐도 달성하는 일일 목표, 연속 학습일, 경험치, 주간 기록
- 휴대폰과 데스크톱에 대응하는 반응형 UI, 키보드 탐색, 접근성 레이블

홈의 **5문제 시작**에서 바로 시작할 수 있습니다. 이어하던 학습이 있으면 **이어서 학습하기**로 돌아옵니다. [전체 콘텐츠 구성](docs/content-curriculum.md)과 [초기 30문제의 학습 설계](docs/content-pilot.md)를 참고하세요.

## 실행

Node.js 20 이상과 Python 3을 사용합니다. 실행 자체에는 npm 의존성이 필요하지 않습니다.

```sh
npm start
```

http://localhost:4173 에 접속합니다. 또는 `dist/`를 정적 웹 호스팅에 올릴 수 있습니다. ES 모듈을 사용하므로 HTML을 파일로 직접 여는 대신 HTTP 서버로 실행해 주세요.

## GitHub Pages 배포

GitHub Pages로 공개 배포된 앱입니다: https://sidebatch.github.io/french-alone/

`main` 브랜치의 `dist/` 또는 패키지 설정을 수정하면 테스트를 통과한 앱을 자동 배포합니다. [Deploy GitHub Pages](https://github.com/sidebatch/french-alone/actions/workflows/pages.yml)에서 배포 결과를 확인하거나 **Run workflow**로 수동 배포할 수 있습니다.

워크플로는 앱 실행에 필요한 `dist/`만 공개합니다. 학습 기록은 방문자의 브라우저에 저장하며, GitHub 계정 로그인은 필요하지 않습니다.

## 검증

```sh
npm ci
npm run check
npm test
```

배포 작업은 게시 후 실제 공개 주소의 설치 설정·아이콘·학습 파일도 확인합니다. 로컬에서도 `npm run check:deployment`로 공개 주소를 점검할 수 있습니다.

PWA 검증은 설치 메타데이터·PNG 아이콘, 오프라인 캐시, 저장 공간 오류, 설치 안내와 사용자 선택 후 업데이트 적용을 확인합니다. 아이콘을 다시 만들 때는 `npm run icons`를 실행합니다. 실제 Android/iOS 설치 창과 기기별 음성은 실기기 확인이 필요합니다.

Node 기본 테스트 러너로 학습 데이터, 정답 판정, 중복 보상 방지, 수준별 복습·진도·스탬프 계산을 확인합니다. jsdom 통합 테스트는 21코스 전체 완주, 수준 전환과 별도 이어하기, 짧은 한 판·오답 재도전, 힌트·카드 도움, 악센트 입력, 저장 복원·초기화와 기존 레슨을 확인합니다. jsdom은 실제 브라우저의 화면 배치나 음성 재생을 검증하지 않습니다.

## 데이터와 음성

학습 기록은 `localStorage`의 `bonjour-french-v1`(기초 레슨·활동), `bonjour-practice-v1`(10문제 도전·복습), `bonjour-practice-drafts-v1`(이어하던 학습)에 저장합니다. 기존 저장 키를 유지하므로 이전 학습 기록도 이어집니다. 서버 전송과 계정 동기화는 없습니다. 최근 200판의 결과를 보관하고, 문항별 기억·보상 상태는 별도로 유지합니다. 브라우저 저장 데이터를 삭제하면 기록도 삭제됩니다. 저장 공간이 제한되면 현재 방문 동안만 기록을 유지하며 안내를 표시합니다.

음성은 기기·브라우저에서 제공하는 프랑스어 음성을 사용합니다. 지원 여부와 품질은 운영체제에 따라 다르며 프랑스어 음성팩이 필요할 수 있습니다. 한글 발음은 근사치로, 정확한 음성 표기(IPA)를 대신하지 않습니다. 화면 글꼴은 Google Fonts를 이용하며 연결이 없으면 시스템 글꼴로 표시합니다.
