# French Alone · 하루 5분 프랑스어

## 앱 바로 실행

**[프랑스어 공부 앱 열기 →](https://bonjour-french-sidebatch.mullaemi.chatgpt.site)**

앱 주소: https://bonjour-french-sidebatch.mullaemi.chatgpt.site

로그인 없이 누구나 사용할 수 있는 공개 앱입니다. 학습 진도와 단어장은 각자의 브라우저에 저장됩니다.

한국어 사용자에게 맞춘 입문 프랑스어 학습 웹앱입니다. 회원가입이나 API 키 없이 바로 시작합니다.

## 기능

- 8개 기초 레슨, 프랑스어·한국어 뜻·한글 발음 안내가 있는 48개 표현
- 표현 익히기 → 6문제 무작위 객관식 퀴즈 → 결과 확인 (5개 이상 정답이면 완료)
- 브라우저 Web Speech API를 이용한 프랑스어 발음 듣기와 느리게 듣기
- 표현 검색, 즐겨찾기 단어장, 오답 모음과 뒤집는 복습 카드
- 일일 목표, 연속 학습일, 경험치, 주간 기록
- 휴대폰과 데스크톱에 대응하는 반응형 UI, 키보드 탐색, 접근성 레이블

## 실행

Node.js 20 이상과 Python 3을 사용합니다. 실행 자체에는 npm 의존성이 필요하지 않습니다.

```sh
npm start
```

http://localhost:4173 에 접속합니다. 또는 `dist/`를 정적 웹 호스팅에 올릴 수 있습니다. ES 모듈을 사용하므로 HTML을 파일로 직접 여는 대신 HTTP 서버로 실행해 주세요.

## 검증

```sh
npm ci
npm run check
npm test
```

Node 기본 테스트 러너로 학습 데이터, 채점·진도·연속 학습 계산을 확인합니다. jsdom 통합 테스트는 레슨 시작, 퀴즈 응답, 저장, 검색, 오답 복습과 초기화 흐름을 확인합니다. jsdom은 실제 브라우저의 화면 배치나 음성 재생을 검증하지 않습니다.

## 데이터와 음성

학습 기록은 `localStorage`의 `bonjour-french-v1` 키에 저장합니다. 서버 전송과 계정 동기화는 없습니다. 브라우저 저장 데이터를 삭제하면 기록도 삭제됩니다. 저장 공간이 제한되면 현재 방문 동안만 기록을 유지하며 안내를 표시합니다.

음성은 기기·브라우저에서 제공하는 프랑스어 음성을 사용합니다. 지원 여부와 품질은 운영체제에 따라 다르며 프랑스어 음성팩이 필요할 수 있습니다. 한글 발음은 근사치로, 정확한 음성 표기(IPA)를 대신하지 않습니다. 화면 글꼴은 Google Fonts를 이용하며 연결이 없으면 시스템 글꼴로 표시합니다.

## 구조

```text
dist/
  index.html     앱 셸과 SVG 아이콘
  style.css      반응형 스타일
  data.js        8개 레슨 및 표현
  core.js        저장 데이터, 퀴즈, 진도 계산
  app.js         화면, 음성, 학습 세션
tests/
  core.test.js   학습 로직 검증
  app.test.js    DOM 통합 검증
.openai/hosting.json  Sites 배포 설정
```

런타임 의존성이나 별도 빌드 과정 없이 `dist/` 그대로 배포합니다. Sites용 소스 연결과 별도로 GitHub 저장소에서도 동일한 소스를 관리합니다.
